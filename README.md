# Cadastro de Livro

Projeto desenvolvido para a disciplina **CIC1007 A01 / Projeto I — Prova Individual 11 (PUC Goiás)**.

**Aluno:** JOSE LUIZ ALBINO CAETANO FRANCO

## Descrição

Pequeno sistema visual para cadastro de livros. O foco da avaliação é a utilização
correta do **Git**, do **GitHub** e do **GitFlow** para registrar todo o ciclo de
desenvolvimento (feature, release e hotfix).

## Como usar

Abra o arquivo `index.html` em um navegador e preencha os dados do livro.
